# Снэпбилд — тестовое задание Fullstack Developer

Адаптивное продолжение продуктового лендинга [snapbuild.ru](https://snapbuild.ru/), выполненное на React и TypeScript.

В рамках тестового задания я вручную воспроизвёл существующую часть сайта по визуальному референсу, сохранил его дизайн-язык и добавил пять новых полноценных секций. Новые блоки не выглядят отдельным шаблоном: они используют ту же сетку, типографику, цветовую палитру, радиусы, интервалы, анимации и интерактивные состояния.

## Воспроизведение исходного сайта

Остальная часть страницы также реализована в коде вручную. Готовая страница или её HTML/CSS не копировались, скриншоты не использовались вместо интерфейса, сторонний шаблон и UI-kit не подключались.

По визуальному референсу были заново собраны:

- фиксированная полупрозрачная шапка и мобильное меню;
- первый экран с градиентным фоном и макетом интерфейса продукта;
- строка логотипов клиентов;
- блок «Одна платформа — весь маркетинг»;
- интерактивный блок форматов контента;
- сравнительная таблица решений;
- блок «Почему команды выбирают Снэпбилд»;
- блок «Безопасность без компромиссов»;
- дорожная карта «Каждый день — новый релиз»;
- FAQ-аккордеон;
- финальный CTA и полный подвал сайта.

При воспроизведении учитывались не только основные цвета и композиция, но и размеры шрифтов, межстрочные интервалы, ширина контейнеров, состояния кнопок, границы карточек, поведение графики и общий вертикальный ритм страницы.

## Интерактивность и визуальные состояния

- мобильное меню;
- вкладки команд и форматов контента;
- автоматическое переключение примеров контента;
- FAQ, в котором одновременно открыт только один ответ;
- клиентская валидация формы и экран успешной отправки;
- hover- и focus-состояния интерактивных элементов;
- анимации появления секций, графиков и элементов интерфейса;
- поддержка `prefers-reduced-motion`.

## Адаптивность

Макет проверен на контрольных разрешениях из задания:

- desktop — от 1280 px;
- tablet — около 768 px;
- mobile — около 375 px.

На меньших экранах колонки и карточки перестраиваются, навигация превращается в мобильное меню, текст и кнопки остаются читаемыми и доступными. Глобального горизонтального скролла нет; широкая сравнительная таблица прокручивается только внутри собственного контейнера.

## Технологии

- React 19;
- TypeScript;
- Vite;
- CSS без стороннего UI-kit;
- локальные шрифты и оптимизированные изображения WebP;

## Локальный запуск

Требуется Node.js 22 или новее.

```bash
npm install
npm run dev
```

После запуска страница будет доступна по адресу, который Vite выведет в терминале — обычно `http://localhost:5173`.

Production-сборка и её локальный просмотр:

```bash
npm run build
npm run preview
```

## Проверки

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

Проект успешно проходит проверку типов, линтер, автоматический тест и production-сборку.

Дополнительно вручную проверены desktop-, tablet- и mobile-версии, загрузка изображений и шрифтов, отсутствие глобального горизонтального скролла, работа меню, вкладок, FAQ и валидации формы.

## Структура проекта

```text
app/
  page.tsx       — компоненты и логика страницы
  globals.css    — стили, адаптивность и анимации
public/
  assets/        — локальные изображения, логотипы и шрифты
tests/           — проверка production-сборки
```

## Ограничения тестовой версии

- Форма демонстрирует клиентскую логику и не отправляет данные на сервер, как и предусмотрено заданием.
- Внешние ссылки ведут на публичные ресурсы Снэпбилда.

## Использование AI

AI использовался как инженерный инструмент для анализа требований, декомпозиции, реализации и проверки результата. Визуальные решения, структура новых секций и итоговые формулировки дополнительно сверялись вручную с исходным сайтом и требованиями тестового задания.
