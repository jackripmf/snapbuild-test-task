# Снэпбилд — тестовое задание Fullstack Developer

Продолжение продуктового лендинга [snapbuild.ru](https://snapbuild.ru/) на React и TypeScript. В проекте воспроизведены ключевые паттерны исходной страницы и добавлены пять новых полноценных секций.

## Опубликованная версия

Ссылка на GitHub Pages будет добавлена после публикации репозитория.

## Локальный запуск

Требуется Node.js 22 или новее.

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
npm run preview
```

## Стек

- React 19 и TypeScript;
- Vite;
- CSS без стороннего UI-kit;
- GitHub Actions для автоматической публикации на GitHub Pages.

## Пять добавленных секций

1. **Один инструмент. Разные команды.** Вкладки со сценариями для маркетинга, дизайна, продаж и продукта.
2. **От брифа до кампании.** Четырёхэтапный процесс с визуальной временной линией.
3. **Встраивается в ваш процесс.** Интеграции с Figma, GitHub, GitLab, CMS, React и API.
4. **Подключение под вашу инфраструктуру.** Варианты пилота, частного облака и собственного AI-стека.
5. **Покажем Снэпбилд на вашей задаче.** Форма с клиентской валидацией, понятными ошибками и состоянием успешной отправки.

## Анализ стилистики

Перед разработкой была изучена актуальная версия исходного сайта на desktop. Зафиксированы используемые паттерны: светло-серый фон, белые поверхности, радиусы 12–20 px, крупная типографика с плотным интерлиньяжем, чёрно-белая основа, персиково-розово-сиреневые градиенты, большие вертикальные интервалы, компактные pill-переключатели и плавные появления блоков.

Новые секции используют тот же ритм, сетку, характер карточек, кнопок и интерактивных состояний. Сторонние шаблоны и UI-kit не использовались.

## Воспроизведённые части исходной страницы

- фиксированная шапка и мобильное меню;
- первый экран с градиентом и макетом интерфейса продукта;
- строка логотипов;
- преимущества платформы;
- интерактивные вкладки форматов;
- сравнительная таблица;
- блок безопасности;
- дорожная карта;
- FAQ-аккордеон;
- финальный CTA и подвал.

## Адаптивность и состояния

Макет рассчитан на desktop 1280+ px, tablet около 768 px и mobile около 375 px. Карточки и колонки перестраиваются, таблица получает локальную прокрутку, навигация превращается в мобильное меню. Для клавиатурной навигации сохранены нативные кнопки и поля. Учтён `prefers-reduced-motion`.

## Что не реализовано

- Форма не отправляет данные на сервер — это соответствует условиям задания.
- Логотипы в демонстрационной строке представлены текстом: они используются только как композиционный элемент тестовой концепции.
- Не копировались закрытые исходники, фирменные шрифтовые файлы и внутренние компоненты продукта.

## Что можно улучшить

- подключить реальные бренд-ассеты после получения разрешения;
- добавить end-to-end тесты интерактивных сценариев;
- настроить реальную CRM-интеграцию формы;
- провести дополнительный аудит с реальными пользователями и устройствами.

## Использование AI

- Codex: анализ требований, декомпозиция, реализация компонентов и стилей, проверка сборки и адаптивных состояний;
- AI применялся как инженерный инструмент: результат проверялся по критериям задания, структура и тексты редактировались под продукт, а сгенерированный код проходил сборку и тесты.
